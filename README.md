## Stack

### Desktop

[![WPF](https://img.shields.io/badge/WPF-512BD4?style=for-the-badge&logo=windows&logoColor=white)](https://learn.microsoft.com/es-es/dotnet/desktop/wpf/)
[![Windows Forms](https://img.shields.io/badge/Windows%20Forms-0078D4?style=for-the-badge&logo=windows&logoColor=white)](https://learn.microsoft.com/es-es/dotnet/desktop/winforms/)

- **WPF (Windows Presentation Foundation)** — interfaces de escritorio ricas y modernas basadas en XAML aplicando el patrón **MVVM**: desacoplamiento total entre vistas y lógica mediante `ViewModels`, *Data Binding*, *Commands* e `INotifyPropertyChanged`.
- **Windows Forms** — desarrollo nativo rápido y estructurado sobre Windows: gestión de formularios modales y contenedores, controles personalizados reutilizables (`UserControl`) y manejo avanzado de `DataGridView`.
- **Acceso a datos en Desktop** — implementación de arquitectura en capas con patrones **DAO (Data Access Object)** y **Repository** para aislar la lógica de negocio del motor de base de datos.

### Backend & APIs

[![ASP.NET Core](https://img.shields.io/badge/ASP.NET%20Core-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)](https://learn.microsoft.com/es-es/aspnet/core/)
[![EF Core](https://img.shields.io/badge/EF%20Core-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)](https://learn.microsoft.com/es-es/ef/core/)
[![Clean Architecture](https://img.shields.io/badge/Clean%20Architecture-2E7D32?style=for-the-badge&logo=arquillian&logoColor=white)](https://learn.microsoft.com/es-es/dotnet/architecture/modern-web-apps-azure/common-web-application-architectures)
[![JWT](https://img.shields.io/badge/JWT-000000?style=for-the-badge&logo=jsonwebtokens&logoColor=white)](https://jwt.io)

- **ASP.NET Core Web API** — diseño y desarrollo de APIs RESTful, configuración de middlewares, inyección de dependencias nativa, políticas CORS y autenticación/autorización con **JWT**.
- **Entity Framework Core** — mapeo objeto-relacional (ORM), migraciones y consultas optimizadas con LINQ.
- **Patrones de Diseño & Arquitectura** — aplicación de **Clean Architecture** (separación en capas `Domain`, `Application`, `Infrastructure` y `Presentation/API`), **Repository Pattern**, **Unit of Work** y **DTOs** para mantener el código desacoplado, escalable y fácil de testear.
