## Stack

### Desktop

[![WPF](https://img.shields.io/badge/WPF-512BD4?style=for-the-badge&logo=windows&logoColor=white)](https://learn.microsoft.com/es-es/dotnet/desktop/wpf/)
[![Windows Forms](https://img.shields.io/badge/Windows%20Forms-0078D4?style=for-the-badge&logo=windows&logoColor=white)](https://learn.microsoft.com/es-es/dotnet/desktop/winforms/)

- **WPF (Windows Presentation Foundation)** — interfaces de escritorio ricas y modernas basadas en XAML aplicando el patrón **MVVM**: desacoplamiento total entre vistas y lógica mediante `ViewModels`, *Data Binding*, *Commands* e `INotifyPropertyChanged`.
- **Windows Forms** — desarrollo nativo rápido y estructurado sobre Windows: gestión de formularios modales y contenedores, controles personalizados reutilizables (`UserControl`) y manejo avanzado de `DataGridView`.
- **Acceso a datos en Desktop** — implementación de arquitectura en capas con patrones **DAO (Data Access Object)** y **Repository** para aislar la lógica de negocio del motor de base de datos.
